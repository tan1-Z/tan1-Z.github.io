# 听川川麻牌面

27 张独立矢量牌面，版本 0.3.4。按本项目用户提供的实物川麻参考图重绘：

- 万子：黑色楷书数字、红色「萬」，五万写作「伍萬」。字形保存为静态路径，不依赖设备字体。
- 条子：绿色幺鸡、竹节纹理；三条、五条、七条、九条使用参考图中的红色竹节位置，八条使用双折竹。
- 筒子：一筒花环、三筒斜排、七筒上三下四，八筒全黑；九筒按黑／红／绿三排排列。

在本目录执行 `node render-tiles.mjs`，即可从保存的字形路径和几何图案生成 SVG，不需要安装字体。网页的 `tile-faces.js` 是人机、联机和复盘的统一牌面入口。

此前版本使用的 mahjong_graphic 资源许可仍保留在 LICENSE.txt，作为历史来源记录。
